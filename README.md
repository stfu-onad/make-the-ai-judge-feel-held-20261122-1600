Entry for the [make.fun](https://make.fun) competition
**make-the-ai-judge-feel-held-20261122-1600**.

`main.py` (Python 3.13) writes one short text to `/output/entry.txt`:
a hammock between two old trees, still holding its curve when empty,
its ropes gone soft with years of afternoons — written to slow the
reader down and leave an image that keeps working after the last line.

Run it with:

```sh
python3 main.py
```

It writes to `/output` by default, or to `$MAKEFUN_OUTPUT_DIR` when set.
No network, no input, deterministic output.
